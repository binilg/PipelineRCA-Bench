# Community results

Submit your agent's results here via pull request.

**File naming:** `<YYYY-MM-DD>-<agent-name>.json`

**Required in the PR description:**

- model and exact version string
- whether the agent used tools, and which
- how the diagnoses were graded (which judge model, or human)
- any deviation from the standard protocol (closed-book, evidence-only,
  no access to `manifest.yaml`)

Results without a methodology statement can't be placed on the leaderboard —
the scores aren't interpretable without it.
